# Goal
App should be the smart activity coach and advisor. It will use data from Garmin API to track my current activities and give recommendations on my health.

# Stack
App should be purely Typescript. It should have backend and frontend separate folders.
Let the backend be based on express, frontend on react. 

# Used APIs
Garmin API that can be used can be retrieved from https://developer.garmin.com/gc-developer-program/personal/swagger-docs/.
you may use client from garmin https://github.com/garmin/connect-personal-api-python
